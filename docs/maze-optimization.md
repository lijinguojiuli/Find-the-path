# 迷宫观察室：本轮全部优化与验收

本轮只修改独立迷宫部分及其 Python 学习模型、测试和文档，原实验台的编辑、机器人和动态障碍流程保持原样。

## 使用步骤

1. 从顶部选择「教学场景」，阅读观察问题，再点击「按推荐组合对比」。
2. 实测结束后自动开始同步播放；可点「同步暂停」后观察，「单步」使两边各展示一个首次探索格子。
3. 暂停后画面不继续探索；短的一边结束后保持最终路径，另一边继续。
4. 「播放选项」提供重置、重播、看最终结果；共同路段在两边都播放完成后标金色。
5. 点击「本步讲解」或直接点击格子。双图中讲解侧会跟随所点击的图；也可手动切换讲解侧。
6. 向下查看差异解读；指标可切换实际扩展、不同格子、重复扩展、容器峰值。
7. 全部实测表提供每种算法的状态与完整数字。「更多实验 → 比较全部 14 种」填满本图统计。
8. 「更多实验 → 多场景实验」用当前两种算法分别运行五张固定地图，结果按场景单列，不混入当前地图统计。
9. 「视图与光效」可以调整格子大小、定位端点、开关光效和调整强度。系统减少动态效果偏好会被尊重。
10. 大屏仍只改变网页布局，保留 Windows 任务栏；F 切换、Esc 退出，H 打开教程。

推荐地图仍为 15×25。进阶尺寸上限仍为 1001×1001。窄窗口的次要菜单会自动留在可见范围内。

## 比较口径

- **不同探索格子**：至少被扩展过一次的不同格子数。
- **实际扩展次数**：真正处理节点的总次数，包含重复处理；`实际扩展 = 不同格子 + 重复扩展`。
- **边扫描**：处理邻居时检查通道边的次数。
- **计算次数**：用于预算，扫描算法还会计入尚不可达格子的扫描，可能多于实际扩展。
- **容器峰值**：当前实现中队列、堆或深度栈的最大条目数。双向取两侧总和；束搜索计入当前层未处理节点与下一层候选。Bellman–Ford 没有队列，显示「不适用」。它不是精确内存占用。
- **同步动画**按首次探索格子对齐，不代表两边花费相同算法计算时间。重复处理的开销由独立统计说明。
- **完整路径比较图**只纳入找到路径的完整结果。达限制与确认不可达单独说明，不以短条形暗示效率更高。
- **中位数耗时**：每次任务先热身 1 次，再测 5 次。地图快照准备、消息、讲解记录、动画和绘图排除；统一搜索统计开销计入。讲解记录在采样结束后单独采集。

扫描和迭代加深等教学算法保留 250000 次预算。达到预算返回 `limited`，不是 `unreachable`；束搜索舍弃分支后失败也不能证明不可达。

## 讲解数据的真实性与资源控制

`SearchTrace` 记录真实首次扩展时的 g 和待选容器大小。h 按该侧目标计算，只有 A* 家族使用 f 排序；终点侧的 g 从终点累计。
容器快照在取出节点后、扩展邻居前采集：队列按出队顺序，堆按真实优先级预览，深度栈显示祖先，扫描算法说明不使用队列。

详细对象快照最多保留前 512 个新探索格子，每份容器预览最多 6 格。超限后仍可查询真实首次扩展评分，但不伪造当时的完整容器。
尚未播放到的格子不展示未来评分。双向连接点有可能在路径上但没有被单独扩展，此时明确解释原因，不捏造 g/f 或提示继续单步。

绘制与算法继续分离。主地图和双图均使用增量栅格，大图不逐帧创建百万个方块。
已完成路径图层会缓存，共同边标色不改变实际路线。
光效强度只影响显示；连续慢绘制会降低光效，稳定后恢复。切换标签页暂停播放。
任务仍使用请求号、地图版本和 Worker 终止隔离，取消及切换地图不会采用旧任务结果。

## 本轮明确修复的缺陷

1. **旧栅格残留**：同一播放对象更换等长结果时，旧缓存错误沿用。先运行回归测试得到失败，再以结果身份参与缓存失效判断修复。
2. **束搜索峰值少计**：旧计数漏掉当前层未处理与下一层候选同时存在的条目。手工 3×5 地图先复现 4 而应为 5，修复后 Python 和网页均为 5。
3. **窄窗口菜单越界**：浏览器实测菜单右缘超过窗口，加入边界偏移与回归测试；修复后右缘位于窗口内。
4. **未扩展路径节点讲解不准确**：双向连接点已在最终路径上，旧讲解仍提示继续单步。回归测试先失败，修复后显示该节点未被单独扩展。
5. **窄画布坐标不一致**：渲染器强制最小绘制尺寸，与 CSS 显示尺寸不符。先复现尺寸断言失败，再改为使用实际 CSS 尺寸，保证点击与绘制坐标一致。
