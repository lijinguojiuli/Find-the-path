# 连续画笔与地形覆盖

寻路实验室的障碍物、高成本和普通地面均支持连续画笔，迷宫实验室保持原有操作。

## 操作

1. 按 1 或选择「障碍物」。在空地按住鼠标左键并拖动，连续添加障碍。
2. 在已有障碍上按下并拖动，连续擦除；经过空地不会反向增加障碍。
   高成本工具（4）始终涂成本 5，可直接覆盖墙；普通地面工具（5）始终恢复成本 1，同时清除墙和高成本。障碍物可以覆盖高成本，覆盖后不残留成本记录。
3. 同一笔来回经过某格只处理一次，不会反复添加、删除。快速拖动会补齐中间格子。
4. 松开左键结束。撤销按钮或 Ctrl+Z 一次恢复整笔，包括被覆盖的地形成本。
5. 起点、终点、机器人当前格不能被覆盖。离开地图不会越界；松开、取消、失去指针捕获、窗口失焦、换工具或撤销会结束当前笔画。
6. 四步教程继续按单击练习；起终点仍按单击设置。触屏继续轻点编辑和滑动地图，鼠标与触控笔支持三种画笔的连续拖动。

## 实现要点

- `web/obstacle-stroke.mjs` 中的 `PaintStroke` 不依赖 DOM。障碍画笔由第一格决定添加或擦除，地形画笔始终使用所选成本；集合记录已经经过的格子，整数线段插值补齐空隙。原 `ObstacleStroke` 接口和回归测试保留，共用同一份拖动逻辑。
- `applyObstacleEdit` 接收明确的目标状态，重复添加、重复擦除都不修改地图。单击的 `applyEdit` 继续保留原来的切换行为，共用端点保护。
- 页面只在本笔第一次实际改图时记录一次快照，后续格子复用这一撤销记录；结束后释放指针捕获，避免鼠标离开后继续绘制。
- 机器人继续通过 `DynamicPlanner.changeObstacle` 改图。路径受影响时立即停止旧路径；同一指针事件内合并为最后一份重规划请求，结果继续检查地图版本与请求编号。
- 绘制和统计按每个指针事件批量刷新，避免每经过一个格子都重建整套界面。
