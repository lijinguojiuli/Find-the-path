# 十种随机地图与视觉选择器

本阶段只扩展独立 `/maze/` 页面，不改变原实验台。网站默认 15×25、种子 20261018 的「不规则散墙」。Python 与网页的生成接口仍默认「带环路」，保留已有调用行为。

## 操作与验收

1. 顶部点击「迷宫风格」，查看十张预览卡。选卡后按当前地图尺寸生成，保留预览所用种子。
2. 主界面的「地图」菜单也可直接选择风格，教学场景单独分组。
3. 点击「换一张」，保留当前风格和尺寸，生成新种子。固定教学场景不显示此按钮。
4. 「调整迷宫与进阶大图」可以输入奇数行列（11–1001）和种子。相同尺寸、类型、种子得到相同地图。
5. 点击「按推荐组合对比」，在同一地图上比较两种算法；切换算法不改变地图。
6. 散墙地图使用浅色连贯墙线、深色空地，接近用户提供的开阔空间示意图。弧线和斜墙由网格近似；搜索和碰撞仍只允许四方向逐格移动。

| 类型 | 生成方式与可观察特点 |
| --- | --- |
| 不规则散墙 | 二次曲线和斜线栅格化，开阔空间内分散短墙，容易看到搜索方向差异 |
| 房间与走廊 | 随机尺寸房间用折线走廊连接，观察房间扩散与门口瓶颈 |
| 自然洞穴 | 随机地形经细胞自动机平滑，形成不规则洞室 |
| 递归分割 | 递归划分矩形区域，分隔墙保留门洞 |
| 螺旋通道 | 随机朝向和间距的单一路线，从外围绕向内部终点 |
| 交错栅栏 | 平行挡板交替留口，需要多次折返绕行 |
| 随机障碍 | 分散障碍与多条可行路线，适合比较探索范围 |
| 长走廊 | 原随机深度优先生成器，狭长且曲折 |
| 多分支 | 原随机 Prim 生成器，短分支较多 |
| 带环路 | 原走廊迷宫增加通道，形成替代路线 |

通常起点是上边入口 `(1, 0)`，终点是下边出口 `(cols-2, rows-1)`。
螺旋通道的终点位于内部末端，界面仍可用「定位终点」找到。所有风格的全部通行格连通。

## 代码结构与关键原理

- `web/maze/generators.mjs` 与 `src/robot_path_lab/maze/generators.py`：七种新生成器，不依赖 DOM 或 Pygame。
- 两端的 `model`：共同尺寸与快照验证、类型注册；三种经典生成器保持原来的随机数调用顺序。
- `worker.mjs`：主地图生成与搜索保持原协议；新增独立的风格预览任务。
- `app.mjs`、`styles-gallery.css`、`renderer.mjs`：卡片选择、菜单、换图和散墙绘制。

墙体用紧凑的单维数组表示，`id=y*cols+x`，值 1 为墙、0 为通行格。随机数算法两端一致；曲线栅格化使用整数运算，避免浮点舍入破坏种子复现。

散墙、洞穴等生成过程可能隔离空地区域。修复过程先用 BFS 标记连通分量，再从所有通行格同时向内部墙体扩展。两个扩展前沿相遇时，通过并查集判断是否仍属于不同分量，并沿前驱链打通连接。原有空地全部保留，不会为了连通而增加外边界缺口，也不需要为每个孤岛重复搜索整张地图。

风格预览使用独立 Worker 和请求状态，打开或关闭选择器不取消主搜索。关闭选择器终止预览 Worker；请求号和版本号阻止旧预览覆盖新内容。

## 实际自动化验证（2026-10-18）

- Python 全套：**1045 passed，8.77 秒**。
- 网页全套：**381 passed，0 failed，0 skipped**。
- 七种新类型 × 五种尺寸（含横向、纵向窄图）× 三个种子：105 张地图逐一检查复现、端点、精确边界开口及全部空地连通。
- 同批 105 张地图检查 Python/JavaScript 的墙体字节与端点完全一致。
- 十种类型在固定种子下形状不同，改变种子会改变地图。三种经典类型与修改前的 SHA-256 固定样例一致。
- 原经典算法特有的奇数房间、树结构断言保留，明确限定为原三类型；新类型增加通用连通、边界与路径检查。
- 新风格上的 14 种算法检查路径首尾、相邻、不穿墙及最优算法成本；有预算的算法允许明确报告 `limited`，不会把它当作不可达。
- 验证散墙空地比例、曲折墙体、螺旋单一路径、连通修复保留空地、预览取消隔离与浅色墙体缓存绘制。
- 七种新类型均通过 1001×1001 的连通和 BFS 路径验证。
