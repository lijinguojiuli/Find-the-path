# 大型迷宫演示

这是独立部分，入口是原实验台顶部的「迷宫演示」，本地地址为 `/maze/`。
原实验台的三算法、地图编辑、机器人移动、动态障碍和 Pygame 原型继续保留。

## 先玩一张，再挑战百万格

1. 初次进入有上手教程；点击「载入教学迷宫」，生成固定种子 42 的 31×31 带环路迷宫。
2. 默认选择 A*，点击「开始搜索」。蓝色表示从起点侧探索，紫色表示双向搜索的终点侧探索。
3. 降低播放速度，暂停后点「单步」；每次只增加一个新探索格子。
4. 点「直接看结果」，金色路径连接起终点。「重置播放」清除覆盖并停在开头，「重播」从头播放。
5. 点「比较八种算法」，同图统计依次出现。点击算法名称切换；地图、种子与尺寸保持相同。
6. 尺寸可设为 301、501、1001，也可分别输入 11–1001 的奇数行列。三种迷宫均保证入口到出口连通。
7. 用右侧可点击小地图、定位起终点、滚动条浏览。滚轮上下、Shift+滚轮左右。
8. 「大屏模式」只改变网页布局，保留 Windows 任务栏。F 切换，Esc 退出；H 随时打开教程。
9. 搜索期间仍可滚动、缩放和定位。「取消计算」终止后台任务并保留当前地图和已完成的统计。
10. 输入偶数行数、超限尺寸或空种子，会显示中文错误，当前地图保持不变。

默认地图为 301×301 带环路，种子 20261018。每格默认 28 像素，可调 16–48；
只显示当前窗口里的格子。小屏设备的概览和对比表在地图下方。
空格在页面主体获得焦点时暂停/继续；聚焦按钮时保留按钮原有键盘操作。
小地图聚焦后 Enter 定位终点、Home 定位起点。切到其他标签页会暂停动画。

## 算法和成本规则

所有算法只走上下左右，进入一个格子付成本 1，不计起点，所以步数与成本相同。
路径包含起终点，起终点相同时成本 0；不可达时路径为空、成本为 null。

| 算法 | 选择下一节点的规则 | 本阶段最短路径保证 |
| --- | --- | --- |
| BFS | 队列逐层访问 | 有 |
| Dijkstra | 优先队列按累计距离 g | 有 |
| A* | g + 曼哈顿距离 h | 有 |
| DFS | 栈，先深入后回溯 | 无 |
| 贪心最佳优先 | 只比较 h | 无 |
| 双向 BFS | 两端按距离层扩展 | 有 |
| 双向 Dijkstra | 两端优先队列按距离扩展 | 有 |
| 加权 A* | g + 1.5h | 无 |

BFS 会先访问距离 0 的格子，再访问距离 1、2……的格子。每一步成本相同时，
第一次发现目标的距离就是最少步数。Dijkstra 的距离数组记录当前最小累计成本，
前驱数组记录这条路线的上一格；到达终点后沿前驱回溯得到路径。

四方向每走一步最多使曼哈顿距离减少 1，因此 h 不超过真实剩余成本。
A* 的 g+h 可以保证最短路径；乘以 1.5 后可能高估，所以加权 A* 不再保证最优。
树形迷宫只有一条可行简单路径，即使非最优算法也可能返回相同路线；带环路更适合观察差异。

双向搜索保存两组距离和前驱，维护当前最佳连接成本。
仅当两侧待处理距离下界之和不小于最佳连接成本时结束，不能简单地在首次相遇时停止。

## 数据流和内存

- 格子编号为 `id = y * cols + x`；`x = id % cols`，`y = floor(id / cols)`。
- 浏览器使用墙体字节数组、整型前驱和紧凑轨迹；索引堆支持降低优先级，同一堆内每格至多一个条目。
- Python 使用不可变墙体字节、紧凑距离/前驱数组和标准库队列、堆，不导入 Pygame。
- 生成器和算法是独立纯逻辑。搜索迭代器产出新探索格子及方向；不负责绘图、等待或文件操作。
- `visitedCount` 表示首次扩展过的不同格子数，双向两侧访问同一格只计一次；重新扩展也不重复计数。
- 每个任务包含请求编号与地图版本。新任务终止旧 Worker，主线程只接受当前任务结果。
- 最多缓存两份完整播放轨迹，八算法统计均保留；被逐出的轨迹在再次选择时重新计算。
- 动画按时间增量更新掩码，不在每一帧复制整个已访问数组。画布只覆盖可见区域，小地图最多 320×320 像素。
- Worker 计时从快照准备完成后开始，消息传输、地图生成、动画和绘图不计入算法耗时。
