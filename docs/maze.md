## 怎么玩

1. 默认 15×25 不规则散墙，种子 20261018，整张地图自动适配视图，起终点同时可见。
2. 选择算法，点击「开始搜索」。蓝色、紫色表示两个方向的探索；光点表示搜索前沿。
3. 暂停后可单步观察；「播放选项 → 看最终结果」显示金色路径与流光。「重置」停在开头，「重播」重新播放。
4. 点击「同步对比」，可并排查看两种算法的路径和探索范围。
5. 下方根据实际结果解释路线是否一样长、探索量相差多少，并解释各自搜索策略。
6. 「更多实验 → 比较全部 14 种」依次运行 14 种算法，探索量条形图和实测表保留全部统计。
7. 点击「迷宫风格」按缩略图选十种类型；「换一张」使用新种子。展开「地图设置」可指定种子和奇数尺寸，范围 11–1001。
8. 推荐小地图完整显示；大地图可按「完整地图」切换到放大查看，再滚动、定位起终点。
9. 光效开关控制探索光点、终点脉冲和路径流光；系统要求减少动态效果时默认关闭。
10. 大屏模式扩展网页布局，保留 Windows 任务栏。F 切换，Esc 退出，H 打开教程。

同步播放、暂停、单步、重播和看最终结果对两边同时生效；短的一方完成后停止，另一方继续。
默认速度 100 格子/秒，只控制播放。推荐地图可以看清每个格子，
教学示例也是 15×25，使用固定种子 20261018。切换算法不改变地图。
实测表位于同步对比面板下方，可在面板中滚动查看图表与数据。

## 算法规则

只允许四方向移动，进入格子成本为 1，不计起点，因此本阶段步数与成本相同。
所有返回路径包含起终点；同起终点成本 0，不可达时路径为空。

| 算法 | 主要策略 | 完成搜索时的最短保证 |
| --- | --- | --- |
| BFS | 队列逐层 | 有 |
| Dijkstra | 优先累计距离 g | 有 |
| A* | g+h | 有 |
| DFS | 栈，深入后回溯 | 无 |
| 贪心最佳优先 | 只看 h | 无 |
| 双向 BFS | 两端分层 | 有 |
| 双向 Dijkstra | 两侧距离下界终止 | 有 |
| 加权 A* | g+1.5h | 无 |
| SPFA | 队列松弛 | 有；本阶段顺序与 BFS 相同 |
| Bellman–Ford | 反复扫描边松弛 | 有 |
| 迭代加深 DFS | 逐次提高深度限制 | 有 |
| IDA* | 逐次提高 g+h 阈值 | 有 |
| 束搜索 | 每层保留 12 个候选 | 无，可能舍弃可行路线 |
| 双向贪心 | 两端朝对方贪心探索 | 无 |

BFS 先处理距离 0，再处理距离 1、2……，所以单位成本下最少步数正确。
前驱数组保存路线的上一格，距离数组保存目前最小累计成本，优先队列选择下一候选。
曼哈顿距离不超过四方向真实剩余成本；乘以 1.5 后可能高估，因此加权 A* 不再保证最优。
双向最优搜索在两侧待处理距离下界之和达到最佳连接成本时结束；双向贪心则允许首次连接返回。

新增六种教学算法采用默认 250000 次计算预算。达到预算返回 `limited`，
界面显示「达上限」，不能当作不可达。束搜索剪枝后失败也返回 `limited`。
重复加深的每轮记录最小到达深度，减少同一分支的重复计算。
树形迷宫只有一条路线，多算法可能走同一路；带环路更容易观察差异。

## 实测差异示例（此前带环路地图）

15×25 带环路、种子 20261018 中，A* 与 BFS 都走 36 步，分别探索 67 与 131 格。
DFS 走 76 步、贪心走 60 步、双向贪心走 56 步。
这说明探索少、速度快和路径短是不同指标；不根据一次耗时声称某算法总是更快。
对比中的两张图使用同一版本地图和移动规则。计算时间排除地图生成、消息、绘制和播放。

## 结构和资源

- 格子编号 `id=y*cols+x`，模型和算法不依赖 Pygame、DOM 或绘制。
- 浏览器使用紧凑数组和索引堆，Python 使用字节、距离/前驱数组及标准库队列、堆。
- Worker 执行生成和搜索；新请求终止旧 Worker，通过请求号和地图版本拒绝过期结果。
- 最多缓存两份完整轨迹，14 种统计保留；对比两种算法只传输这两份轨迹。
- 动画按时间增量更新探索掩码；放大时仅绘制可见格，完整大图使用紧凑栅格，避免逐帧绘制百万个方块。
- 光效只负责显示，不改变算法路径、统计或机器人状态。
