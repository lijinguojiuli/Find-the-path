    探索 · 对比 · 解释

    一起看懂算法为什么这样走。

    1. 选教学场景。每张小地图都有观察问题和推荐算法组合。
    2. 开始或同步对比。点播放、暂停或单步；一方先完成后，另一方会继续。
    3. 打开本步讲解。点击格子看 g/h/f，以及取出节点后的容器预览。最多保留前 512 个新探索格子的详细快照。
    4. 分清比较指标。不同格子数不等于实际扩展次数。达上限不代表不可达，也不参加完整路径比较。
    5. 多次实测。热身后采样 5 次取中位数；多场景实验使用固定地图，每张分别统计。

    大屏模式保留 Windows 任务栏。F 切换，Esc 退出，H 打开教程。光效支持手动强度和性能自动降级。
