为什么走法不同？

先看顺序，再看路线

  1. 从教学示例开始，选择 A* 并搜索。
  2. 点击「暂停」，用「单步」观察一个新节点。
  3. 点击「直接看结果」，金色路线连起起终点。
  4. 比较八种算法，再点击表格里的算法名称。

DFS、贪心和加权 A* 不保证最短。树形迷宫往往只有一条路线；切换「带环路」更容易看出路线差异。

独立迷宫演示 · 原实验台保留地图编辑、机器人移动与动态重新规划。
从第一步开始

这么大的迷宫，怎么玩？

  1. 先用小地图练习。载入 31×31 教学迷宫，绿色是起点，珊瑚色是终点。
  2. 观察算法。选好算法，点击「开始搜索」，蓝色节点按访问顺序出现。
  3. 控制播放。暂停后单步，或直接看金色路径；速度滑块只改变动画。
  4. 挑战大迷宫。生成 301 或 1001 的地图，用右侧小地图、定位按钮和滚动条浏览。切换算法不会换图。

「大屏模式」扩大网页布局，保留底部系统任务栏。空格暂停/继续，F 切换大屏，H 打开教程。
